# The admin manual

For the people who run the foundation's website day to day. No technical
knowledge assumed. Every chapter is a job you might have to do, with the
screen it happens on.

The admin panel is at **your site address followed by `/scghf-office`**
(for example `https://www.example.org/scghf-office`). It is also linked
from **Help** at the bottom of the panel's menu, where this manual is
shown inside the panel itself.

**Two rules that cover most of the manual:**

1. **Nothing you do in the admin can lose money.** Donations cannot be
   edited or deleted, only refunded, and a refund needs two people.
2. **If a screen says "needs attention", "needs review" or shows a red
   badge, read it before doing anything else.** It is telling you about a
   real problem, in plain words.

The screenshots are from a practice site with made-up names. Your site
will have the foundation's own colours, logo and content.
